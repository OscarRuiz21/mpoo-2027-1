# Código de la S10 · Estructuras de selección

Un archivo por tema, cada uno con su propio `main`. Se corren de uno en uno, sin
compilar a mano y sin proyecto: basta Java 21.

```
java Booleanos.java
```

| Archivo | Qué muestra |
|---|---|
| `Booleanos.java` | Condiciones, `&&` y `||` con cortocircuito, y por qué `0.1 + 0.2 == 0.3` es `false` |
| `Ifs.java` | `if`, `if-else` y la escalera `else-if`; por qué importa el orden |
| `Ternario.java` | `condicion ? valorSi : valorNo`, y cuándo estorba |
| `SwitchClasico.java` | `switch` con `break` y la caída en cascada cuando falta |
| `SwitchModerno.java` | La forma con flecha, varios valores por `case` y el `switch` que devuelve un valor |
| `EnumDias.java` | `enum` con `switch`, y qué gana frente a `int` o `String` |
| `Anidamiento.java` | El mismo retiro, anidado y con salidas tempranas |
| `MathDemo.java` | `Math` y cómo se comparan de verdad dos decimales |
| `MenuInteractivo.java` | El menú de la clase, con `Scanner` |

Los dos que empiezan con `TuTurno` están incompletos a propósito: son los ejercicios
de la sesión. Traen los casos de prueba con el resultado esperado.

Nada de esto usa ciclos: las repeticiones son de la S12.
