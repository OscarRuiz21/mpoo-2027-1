Parte 1 · Un ejemplo completo, con otra clase

Así se ve una clase con todo lo que vas a escribir hoy. No es la de la práctica: es un Alumno, para que veas la forma y luego la apliques a Producto y Expendedora.

public class Alumno {

    // CONSTANTE: static final, en MAYÚSCULAS, no cambia nunca
    static final int EDAD_MINIMA = 17;

    // ATRIBUTO STATIC: uno solo, compartido por todos los alumnos
    static int totalAlumnos = 0;

    // ATRIBUTOS: cada alumno tiene los suyos
    String nombre;
    int edad;

    // CONSTRUCTOR: mismo nombre que la clase, sin tipo de retorno
    Alumno(String nombre, int edad) {
        this.nombre = nombre;           // this.atributo = parametro
        if (edad < 0) {                 // if / else: validar lo que llega
            this.edad = 0;
        } else {
            this.edad = edad;
        }
        totalAlumnos++;                 // cuenta a este alumno
    }

    // MÉTODO con escalera if / else if / else
    String etapa() {
        if (edad < 18) {
            return "MENOR";
        } else if (edad < 30) {
            return "JOVEN";
        } else {
            return "ADULTO";
        }
    }

    // MÉTODO con ternario:  condicion ? siTrue : siFalse
    String puedeInscribirse() {
        return edad >= EDAD_MINIMA ? "SI" : "NO";
    }

    // MÉTODO static: se llama con el nombre de la clase
    static int getTotalAlumnos() {
        return totalAlumnos;
    }
}

Y así se usa:

Alumno a = new Alumno("Ana", 19);
Alumno b = new Alumno("Beto", -3);

a.etapa()                  // "JOVEN"
a.puedeInscribirse()       // "SI"
b.etapa()                  // "MENOR"   (su edad se guardó como 0)
Alumno.getTotalAlumnos()   // 2

El switch clásico, con otro ejemplo

int numero;
switch (dia.trim().toUpperCase()) {   // " martes " se vuelve "MARTES"
    case "LUNES":
        numero = 1;
        break;                        // sin break, sigue al case de abajo
    case "MARTES":
        numero = 2;
        break;
    default:                          // ningún case coincidió
        numero = -1;
}
return numero;

Con un enum es igual. El case se escribe corto, case DIEZ:, sin el nombre del enum.

Expendedora m = new Expendedora("Edificio Q", 15);  // 10 piezas de cada producto, saldo 0

m.insertar(Moneda.DIEZ);        // saldo 10
m.insertar(Moneda.CINCO);       // saldo 15

m.insertar(Moneda.DOS);         // saldo 17
m.insertar(Moneda.UNO);         // saldo 18
m.comprar("A1");                // "ENTREGADO, CAMBIO $0"   papas: 9, saldo: 0, ventas: 1

m.comprar("C3");                // "CODIGO INVALIDO"

m.insertar(Moneda.DIEZ);        // saldo 10
m.insertar(Moneda.DIEZ);        // saldo 20
m.insertar(Moneda.DIEZ);        // saldo 30
m.comprar("B1");                // "ENTREGADO, CAMBIO $15"   chocolate cuesta 15; ventas: 2

En una máquina creada con 0 piezas, comprar("B1") da "AGOTADO" aunque tenga saldo: primero se pregunta si hay piezas y después si alcanza el dinero.

Parte 3 · Cómo sabes que quedó

javac P5Seleccion.java      # compila también Moneda, Producto y Expendedora

cuando ya está PRODUCTO 1 papas con 15 piezas 10 10 ok ... 18 getVentasTotales() 2 2 ok --------------------------------------------------------------------------------- 18 DE 18 Listo. Toma la captura de esta tabla y pegala en tu bitacora.

Lo que más truena

  • La 7 da null (DISPONIBLE): te faltó this. al guardar la ubicación. Compila, pero no guarda nada.
  • Muchas dan truena: NullPointerException: un Producto de la máquina se quedó en null. Te faltó crearlo con new en el constructor.
  • La 9 truena y la 10 da true, false: no limpiaste el código con trim() y toUpperCase().
  • La 16 da FALTAN $5: el orden de tu escalera. Primero se pregunta si hay piezas, luego si alcanza el dinero.
