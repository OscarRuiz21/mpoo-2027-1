# Entregas

Una carpeta por persona, con tu **primer apellido y tu primer nombre, en minúsculas y sin
acentos, unidos por un guion bajo** (así dos personas con el mismo apellido no chocan):

```
entregas/
└── ramirez_ana/
    ├── p01/
    └── p02/ … p12/
```

Cada práctica se entrega desde una rama `pNN-apellido` como **pull request** al
repositorio. Tu carpeta la creas en el Lab 0. Cada quien toca solo la suya.
