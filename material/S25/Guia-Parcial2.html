Los tres errores que más puntos costaron en el Parcial 1.
  1. Imprimir en lugar de devolver. Si el enunciado dice «devuelve», el método termina con return, no con System.out.println.
  2. Dejar el código en blanco. Una clase con la cabecera, el constructor y el método a medias vale puntos. En blanco vale cero.
  3. Describir en lugar de contestar. Si te preguntan qué imprime, escribe la salida exacta. Si te preguntan por qué, da la razón, no repitas la pregunta.

3. Práctica de la Parte A · opción múltiple

Elige una sola opción y anota por qué las otras tres no son.

  1. Herencia. ¿Qué imprime new B(); ?
    class A { A() { System.out.print("A"); } }
class B extends A { B() { System.out.print("B"); } }
    1. B
    2. BA
    3. AB
    4. No compila
  2. Herencia. Padre solo tiene el constructor Padre(int x). ¿Qué pasa con esta clase?
    class Hija extends Padre {
    Hija() { }
}
    1. Compila: Java llama a Padre(0)
    2. No compila: falta llamar a super(...) con un int
    3. Compila, pero truena al crear una Hija
    4. No compila: una hija no puede tener constructor
  3. Polimorfismo. Perro sobrescribe sonido() para devolver "Guau". ¿Qué imprime?
    Animal a = new Perro();
System.out.print(a.sonido());
    1. Guau
    2. ...
    3. No compila
    4. Truena al ejecutar
  4. Polimorfismo. ladrar() solo existe en Perro. ¿Qué pasa?
    Animal a = new Perro();
a.ladrar();
    1. Ladra, porque el objeto es un Perro
    2. Truena al ejecutar
    3. Compila y no hace nada
    4. No compila: la variable es de tipo Animal y Animal no tiene ladrar()
  5. Polimorfismo. ¿Cuál es la diferencia entre sobrescribir y sobrecargar un método?
    1. Son lo mismo
    2. Sobrescribir: mismo nombre y otros parámetros en la misma clase. Sobrecargar: misma firma en la hija
    3. Sobrescribir: la hija vuelve a escribir un método del padre con la misma firma. Sobrecargar: mismo nombre con otros parámetros
    4. Sobrescribir solo se puede con métodos static
  6. Abstracción. Figura es una clase abstracta. ¿Qué pasa con Figura f = new Figura(); ?
    1. No compila: una clase abstracta no se puede instanciar
    2. Compila y crea una figura vacía
    3. Truena al ejecutar
    4. Compila solo si Figura no tiene métodos abstractos
  7. Interfaces. ¿Cuál declaración es válida en Java?
    1. class Pato extends Ave, Nadador
    2. class Pato implements Ave extends Nadador
    3. class Pato extends Volador implements Ave (con Volador interfaz y Ave clase)
    4. class Pato extends Ave implements Volador, Nadador
  8. Interfaces. Volador declara void volar(); ¿Qué pasa con esta clase?
    class Dron implements Volador {
    void volar() { }
}
    1. Compila sin problema
    2. No compila: el método debe ser public, como en la interfaz
    3. No compila: falta la palabra abstract
    4. Compila, pero volar() no se puede llamar
  9. Encapsulamiento. saldo es private en Cuenta. ¿Cómo lo consulta la clase CuentaAhorro, que hereda de Cuenta?
    1. Con this.saldo
    2. Con super.saldo
    3. Con getSaldo(), si Cuenta lo ofrece
    4. No hay forma
  10. Encapsulamiento. ¿Para qué sirve validar dentro de un setter o de un constructor?
    1. Para que el programa corra más rápido
    2. Para que el objeto nunca quede en un estado inválido, lo use quien lo use
    3. Para poder heredar de la clase
    4. Para no tener que escribir getters
  11. Excepciones. ¿Qué imprime?
    try {
    int[] a = new int[2];
    a[2] = 1;
    System.out.print("A");
} catch (ArrayIndexOutOfBoundsException ex) {
    System.out.print("B");
} finally {
    System.out.print("C");
}
    1. ABC
    2. AC
    3. B
    4. BC
  12. Excepciones. ¿Qué excepción lanza Integer.parseInt("dos") ?
    1. NumberFormatException
    2. InputMismatchException
    3. NullPointerException
    4. ArithmeticException
  13. Excepciones. Un constructor hace throw new IllegalArgumentException("precio negativo"). Quien crea el objeto no usa try-catch. ¿Qué pasa?
    1. El objeto se crea con precio 0
    2. No compila
    3. El programa termina con la traza de la excepción
    4. La excepción se ignora
  14. Polimorfismo. Perro y Gato heredan de Animal. ¿Qué pasa?
    Animal a = new Gato();
Perro p = (Perro) a;
    1. No compila
    2. Compila y truena con ClassCastException
    3. Compila y convierte el gato en perro
    4. Compila y p queda en null
  15. Herencia. ¿Qué efecto tiene declarar una clase como final?
    1. No se pueden crear objetos de ella
    2. Sus atributos no pueden cambiar
    3. Todos sus métodos son abstractos
    4. Ninguna clase puede heredar de ella
  16. Herencia. ¿Para qué sirve escribir @Override?
    1. Para que el compilador avise si en realidad no estás sobrescribiendo nada
    2. Para que el método corra más rápido
    3. Es obligatorio para heredar
    4. Para volver abstracto el método

4. Práctica de la Parte B · lee el diagrama

Un cine cobra por asiento cada boleto y además devuelve dinero de lo que sea reembolsable.

Contesta con tus palabras, en una a tres oraciones:

  1. ¿Cuáles tipos del diagrama no se pueden crear con new? Di por qué en cada caso.
  2. Se ejecuta Boleto v = new Estudiante("Sala 2", 2); y luego v.precio(). ¿De qué clase es el método precio() que corre y por qué?
  3. ¿Qué método está obligada a escribir la clase Combo y quién la obliga? ¿Qué pasa si no lo escribe?
  4. ¿Se puede guardar un objeto Combo en un arreglo Boleto[]? ¿Y en un arreglo Reembolsable[]? Explica las dos respuestas.
  5. sala es private en Boleto. ¿Cómo obtiene ese dato un objeto Estudiante? ¿Qué pilar se está aplicando y para qué sirve?
  6. Lista todos los métodos que puedes llamar sobre un objeto Vip, incluidos los heredados, y di de dónde viene cada uno.

5. Práctica de la Parte C · escribe el código

Usa el diagrama del cine. Esta es la clase Boleto, ya escrita:

public abstract class Boleto {
    private final String sala;
    private final int asientos;

    protected Boleto(String sala, int asientos) {
        if (asientos <= 0) {
            throw new IllegalArgumentException("Los asientos deben ser mayores que cero");
        }
        this.sala = sala;
        this.asientos = asientos;
    }

    public abstract double precio();

    public String getSala() {
        return sala;
    }

    public int getAsientos() {
        return asientos;
    }
}
  1. Escribe completa la clase Estudiante del diagrama. Un boleto de estudiante cuesta 50 pesos por asiento. El método precio() devuelve el valor con return, no lo imprime.
  2. Escribe el método static double total(Boleto[] lote), que devuelve la suma de precio() de todos los boletos del arreglo. El arreglo puede traer normales, de estudiante y VIP en cualquier orden. No uses if ni instanceof para distinguir el tipo.
  3. Para practicar interfaces: escribe completa la clase Combo del diagrama. Su método reembolsar suma el monto recibido a devuelto.
  4. Para practicar excepciones: sin correrlo, ¿qué imprime este programa? Después explica por qué no se imprime Creado. 
    public class Demo {
    public static void main(String[] args) {
        Reembolsable[] cosas = { new Vip("Sala 5", 2), new Combo() };
        for (Reembolsable r : cosas) {
            r.reembolsar(40);
        }
        try {
            Boleto b = new Estudiante("Sala 2", 0);
            System.out.println("Creado");
        } catch (IllegalArgumentException ex) {
            System.out.println("No se pudo: " + ex.getMessage());
        } finally {
            System.out.println("Fin");
        }
    }
}
