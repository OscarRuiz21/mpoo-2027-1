Este es el repositorio del curso. Aquí subo yo las guías y el material de apoyo, y aquí
entregas tú tus prácticas. Todo el semestre pasa por este lugar, y **todos trabajamos en
este mismo repositorio**, como un equipo en una empresa.

## Tu primer paso

**[Laboratorio 0 · Entorno de trabajo y primer pull request](https://oscarruiz21.github.io/mpoo-2027-1/guias/Lab-00-Entorno-y-Git.html)**

Ábrelo, elige tu sistema operativo arriba y sigue las partes en orden. Las Partes 0 a 2
son tu entorno; las Partes 3 y 4 son Git, GitHub y tu primera entrega.

## Cómo funciona el repositorio

```
mpoo-2027-1/
├── guias/           ← las guías de laboratorio (las subo yo)
├── material/        ← los decks de las clases de teoría (los subo yo)
├── apoyo/           ← código de ejemplo de cada tema (lo subo yo)
└── entregas/        ← aquí van tus prácticas, en tu carpeta
    └── apellido_nombre/
        ├── p01/
        └── p02/ … p12/
```

Cuatro reglas:

1. **Necesitas ser colaborador**: me mandas tu usuario de GitHub y aceptas la invitación
   que te llega. Sin eso no puedes subir nada.
2. **Nunca trabajas en `main`**: está protegida. Cada práctica vive en una rama
   `pNN-apellido`, y se entrega como **pull request** que yo reviso e integro.
3. **Cada quien toca solo su carpeta** de `entregas/`. Así 27 personas conviven en el
   mismo repositorio sin pisarse.
4. **Tu entrega es el PR.** La hora que cuenta es la de tu último push a la rama.

## La rutina de cada semana

Está paso a paso en la
[guía de Git y GitHub](https://oscarruiz21.github.io/mpoo-2027-1/guias/Guia-Git-GitHub.html)
(y resumida en [`GIT-CHEATSHEET.md`](GIT-CHEATSHEET.md)): traer lo nuevo, crear tu rama,
trabajar en tu carpeta, `status`, `add`, `commit`, `push`, abrir el PR.
